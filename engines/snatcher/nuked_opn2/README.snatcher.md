# Native Snatcher FM generator dependency

The four upstream files in this directory are unmodified Nuked-OPN2 from the official repository at commit `335747d78cb0abbc3b55b004e62dad9763140115`. Exact file hashes are recorded in UPSTREAM.json. Copyright notices remain in both source files and the original LGPL2.1 text remains in LICENSE. The library grants version2.1 or later; the independently implemented engine retains its GPL3-or-later licensing. Any future distribution must retain these notices and satisfy source/relinking obligations; this phase creates no release.

This dependency is only a compatible six-voice FM sound generator. It contains no game data, scenario implementation, CPU, BIOS, disc, graphics, PCM stream manager, or emulator frontend. The native Snatcher player owns the music language, source resource lookup, source pitch/level modulation and event ownership. An FM sound generator is explicitly permitted by the Phase8 architecture.

Existing ScummVM TownsPC98_FmSynth was inspected first. Its source explicitly rejects enabled hardware LFO and masks FMS to two bits; the game has a three-bit field and hardware-LFO controls. Adopting an existing licensed audio-only generator avoids silently dropping those effects or recreating a complete sound generator. The temporary allocation-only Towns API experiment was removed; no unrelated sound backend is modified.

Our fm_synth.cpp adapter normalizes independently recovered native instrument/channel events into the generator's API, including source operator order0/8/4/12. It queues writes and respects the generator's own audio busy handshake while rendering; it does not schedule original CPU instructions. Exact rational NTSC sound timing is53693175/(7*6) generator steps/second. PCM output uses integer box integration, fixed signed9-bit-to-S16 scaling128 and the YM2612-mode idle-pin baseline3; there is no fitted per-song gain or game clip special case. YM2612-mode DAC-ladder behavior is explicitly marked not verified by upstream; original mix/filter fidelity is measured separately, never inferred from decoded command correctness.

The ScummVM adapter owns a private device-less mixer solely to combine this FM stream with our existing native PCM percussion. The main CE mixer receives generated PCM; no rendering callback executes the story interpreter. All copyrighted original comparison media remains private.
