# ScummVM Comfort Edition v0.1.5

Release candidate for the complete portable Windows x64 Comfort Edition, based
on upstream ScummVM 2026.4.0. Publication awaits owner acceptance of the exact
candidate, source commit and checksums. Game data is not included.

## New since v0.1.4: Gooka (experimental)

- Select Czech or English through Game Options → Game → Language, using the
  original Czech Windows CD files and the same saves. Restart the game after
  changing language. English text is embedded in the executable; no external
  translation installation or network access is needed.
- All 835 resource IDs are mapped: 819 English translations and 16 deliberately
  retained entries. Includes the 127 owner-supplied professional editorial
  revisions. Seven existing contextual-review flags remain; this is not a
  claim of complete editorial certification.
- English dialogue wraps to the game display. Encyclopaedia text fits the
  original book columns while retaining formatting and illustration markers.
  Original Czech text and layout remain available.
- The off-screen woman's opening line now receives a subtitle when subtitles
  are enabled, using the existing voice timing. The man's reply is retained.
- Optional **Scale videos to full height** in Game Options → Game scales the
  intro and ending movies to fit the game screen while preserving aspect ratio,
  without cropping. It is off by default. For an existing target with cached
  options, launch it once and reopen Game Options to refresh the option list.

Gooka requires the original Czech game files. Speech, video and text baked into
images remain original; English text support does not translate Czech audio or
video. The engine remains experimental: no full-game completion test has been
performed, and some rooms/NPC behavior remain incomplete upstream. Intro/ending
frame sizing, intro skipping and ending completion were checked during focused
development validation; audible audio and comprehensive save-dialog navigation
remain incompletely verified. Seven context flags are retained for IDs 856,
918, 1338, 1339, 1373, 3216 and 3221.

## CE identity and internal maintenance

- The application version output and About dialog identify Comfort Edition
  v0.1.5 separately from its unchanged ScummVM 2026.4.0 foundation. Upstream
  version values used by engines remain unchanged.
- Gooka is maintained at the reviewed fermix42/scummvm revision
  `ff162f3b121aa8e9a98d5d592f5f3f16d97110a4`. The importer requires an exact
  revision, verifies source hashes and protects local changes. Bilingual,
  subtitle, video and editorial verification receipts accompany the source.
- Publication now uses the explicit immutable-candidate publisher rather than
  rebuilding on a release tag. It verifies tag/source identity and checksums,
  stages a draft, checks uploads and the downloaded public ZIP, refuses
  conflicting assets, and supports safe resumption. PowerShell executable
  resolution and JSON-argument handling fixes are included. The obsolete
  automatic publishing workflow remains permanently disabled.
- Candidate packaging retains complete runtime dependencies, resources,
  licenses and CE documentation; deterministic ZIP assembly and non-overwrite
  safeguards remain in use. Historical v0.1.4 readiness documentation is retained.

These are all post-v0.1.4 development changes recorded in Git. There are no
additional non-Gooka engine fixes or upstream upgrades in this release.

## Existing CE functionality retained

The complete enabled engine set and prior CE customizations remain included:
desktop window layouts/scaling, play sessions and achievements, existing cheat
options, MI4 Windows/PS2 support and session save banks, AGS and Nox support,
Space Quest V: Trash Talkin' Edition support, and the opt-in native Test CLI.
These features and strict portable storage already shipped in v0.1.4; they are
not new v0.1.5 features.

## Portable installation and upgrades

Extract the entire ZIP into a **short, writable directory**, for example
`D:\Games\ScummVM CE`, and run `scummvm.exe`. Keep its DLLs and resource files
together. Avoid protected installation directories and long nested paths.

Strict executable-relative storage is permanent CE architecture. Configuration,
saves, sessions, achievements, screenshots, logs, cache and temporary application
data stay inside the installation directory. There is no AppData/profile
fallback. Official ScummVM configuration and saves are not imported or shared
automatically; external original game-data directories remain supported.

**Preserve the complete installation directory and its portable data when
upgrading.** Back it up before replacing application files; do not replace an
existing configured INI with the package's fresh INI. The documented Windows
path-length limitation remains; a short installation path is recommended.

## Validation and limits

Final candidate checks cover this build's CE identity, engine registration,
Gooka revision/resources, dependency closure and package integrity. Prior
Gooka development receipts cover bilingual rendering/shared saves, opening
subtitles, AVI scaling and the 127 editorial revisions. Earlier MI4, AGS, Nox,
storage and general CE acceptance evidence is reused for retained functionality;
it is not represented as a fresh gameplay run of the v0.1.5 executable.

The final readiness record supplies the exact source commit, build result,
executable and ZIP hashes. Repeat ZIP assembly is byte-identical for the same
inputs. **Independent bit-identical executable rebuilding has not been verified.**
No signing, installer or automatic upgrade/migration is provided.
