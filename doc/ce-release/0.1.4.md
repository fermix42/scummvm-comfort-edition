# ScummVM Comfort Edition v0.1.4

Windows x64 portable release candidate, based on official ScummVM 2026.4.0.
Proposed tag: `v0.1.4`. Publication requires the owner's final authorization.

Changes since CE v0.1.3:

- Added the experimental Gooka engine, pinned to Kungergely/scummvm revision
  `66b8f9703e73fa7a2c9bd8e81ea312a824e97fdf`, with its original credits and a
  local-edit-protected manual importer. The known Czech Windows CD v1.0.3.0
  detection remains unchanged. Gooka is unstable upstream; incomplete room/NPC
  behavior remains and this is not a full-game completion certification.
- Strict executable-relative Windows storage is permanent CE architecture,
  accepted November 8, 2026. Configuration, saves, sessions, achievements,
  screenshots, logs, downloaded data, caches and temporary files stay inside
  the executable's directory tree. External managed CLI paths are rejected;
  legacy external INI storage settings resolve to local defaults. There is no
  AppData/Documents fallback or automatic import of existing data.
- Integrated the official ScummVM 2026.4.0 engine/resource baseline while
  retaining all prior CE customizations and the complete enabled engine set.
- Added Monkey Island 4 Windows/PS2 play-session save banks, gallery metadata
  and edition-appropriate controller behavior. Existing saves are preserved.
- Added Space Quest V: Trash Talkin' Edition 0.2.12 support and session ownership
  fixes, plus optional Battle Cruiser probe cheats. Fan/game assets are not
  distributed; original editions remain supported.
- Included the opt-in native gameplay test CLI with owned disposable test roots,
  headless/offscreen validation, and local CE session/save inspection. Normal
  launches do not activate the test interface.
- Retained Nox Archaist support, existing cheats/patches, achievements/session
  features, desktop window layouts, scaling, themes and other CE enhancements.

Extract the **whole** archive into a short writable folder such as
`D:\Games\ScummVM CE`. Keep DLLs, resources, licenses and writable subdirectories
together. Upgrade with CE closed and preserve existing config/saves. Do not
overwrite personal state with another installation's files. Absolute external
game-data paths may need updating after moving to another computer.

Game files are not included. Gooka needs the owned CD's `0.BIN` through `11.BIN`
and its videos. A supplied patch containing only the original `GAME.EXE` is not
used by this engine; the tested original BIN detection signatures already match.

Known limits:

- Deep custom save paths/long sidecar names can exceed existing Windows or
  C-runtime limits. Use a short installation path; CE reports errors rather
  than falling back to the profile.
- Windows/graphics-driver caches and shared SAPI resources are outside CE-managed
  storage. Filesystem notification tests are not process-attributed kernel traces.
- Gooka validation is representative, not an end-to-end playthrough or proof of
  every optional engine/debug path. Physical audio, display/DPI/controller and
  live achievement synchronization acceptance remain separate where unverified.
- The release-readiness report identifies the tested executable and package
  SHA256 values, exact source commit, tool/dependency identity and any failures.
  A clean source build is required; independent bit-identical compiler output is
  not implied. ZIP assembly is deterministic for identical packaged inputs.

See `FORK-CHANGES.md`, upstream `NEWS.md`, `BUILD-MANIFEST.json`,
`CE-RELEASE.json` and the release-readiness report for details and provenance.
No installer, automatic updater or code signing is provided.
