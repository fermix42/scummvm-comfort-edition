# ScummVM Comfort Edition v0.1.7

Windows x64 release based on ScummVM 2026.4.0.

## AGS detection

- Adds exact fingerprints from the eXoScummVM collection to existing AGS game
  IDs. The fingerprints use the detection filename, the MD5 of the first 5,000
  bytes, and the full byte count. Game data is distributed separately.
- Classifies Marty Chonks in Dances With Camels as AGS 2.50 (data format 18) and
  Project Evilspy: FenderQ Meets Jeeforce for Lunch as AGS 2.51 (data format 19).
  The corrected full releases are eligible to launch for gameplay testing.
- The bundled AGS engine supports compiled formats through 3060114. The
  detector manifest records inventoried builds above that limit and any other
  unresolved files.

Gameplay completion for the two reclassified games remains unverified. The
detector manifest records the scope and provenance of gameplay evidence.

## Installation

Extract the complete ZIP to a short, writable directory. Keep the executable,
DLLs and resources together. Back up the entire previous installation and
preserve its portable configuration and saves during upgrades. The included
fresh INI is for new installations. CE keeps application data under its
installation directory and uses separate profiles from official ScummVM.
