# ScummVM Comfort Edition v0.1.8

Windows x64 release based on ScummVM 2026.4.0. Includes the native Nox Archaist,
Snatcher and Gooka engines alongside the other CE engines.

## Snatcher

- Adds the experimental native Sega CD engine, integrated CE save slots,
  autosave, save gallery, session ownership and F12 investigation captures.
- Fixes presentation stalls and scene composition, including Napoleon's sneeze,
  the hospital ambush and Jaime's cutscene. Disables Release GL polling.
- Keeps the flashlight command menu stationary. The mouse wheel selects a
  command; left click executes it at the flashlight's center.
- Adds the Infinite Health cheat for shooting sequences through CE's cheat UI.
  Entering KONAMI on the in-game computer enables Uncensored immediately.
- Replaces bulky save snapshots with a compact native format and reduces cold
  startup work. Existing supported saves remain loadable; new and replaced
  saves use the new format and require a compatible updated executable.

## Gooka

- Loads the English translation from the bundled `gooka.dat`, allowing data-only
  translation updates. There is no compiled English fallback. Selecting English
  with missing or invalid translation data produces a clear error.
- Packages `gooka.dat` and `snatcher-decensor.dat` beside `kyra.dat` and the
  executable, with release checks for missing or stale data.

## Nox Archaist and CE

- Restores Nox in the Windows distribution with the current native engine,
  title audio, original menu and gameplay presentation fixes, assisted play,
  and v119 gameplay parity improvements.
- Supports the original Nox Archaist base v119 HDV. Lord of Storms v137 is
  outside the supported scope. Original game data is not included.
- Improves launcher Play Session selection, persistence and save ownership.
  Leaving a game no longer asks to mark its session complete.

Snatcher and Gooka remain experimental. This release's automated regression
checks do not constitute fresh full-game completion or personal display/audio
acceptance. Independent bit-identical executable rebuilding is unverified.

## Installation

Extract the complete ZIP to a short, writable directory. Keep the executable,
DLLs and resources together. Preserve the complete previous installation
directory, including portable configuration, profiles, sessions and saves, when
upgrading. The bundled fresh `scummvm.ini` is for new installations: retain your
existing INI during an upgrade. CE stores application data beneath its own
installation directory and uses separate profiles from official ScummVM.
