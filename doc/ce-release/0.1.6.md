# ScummVM Comfort Edition v0.1.6

Windows x64 maintenance release based on ScummVM 2026.4.0. Game data is not included.

## Fixed: all-engine detection crash

Detecting the complete Adventure: Welcome to the Genre distribution could crash
after AGS had already matched the game. WAGE fallback probing interpreted bytes
in the game's `.001` file as a Macintosh resource header and accepted a map
extending beyond the file boundary.

The Macintosh resource parser now validates complete fork, data and map regions
with overflow-safe arithmetic. Type tables, reference lists and resource names
must remain inside the declared map; resource lengths and payloads must remain
inside the declared data region. Invalid candidates are rejected before resource
allocation and enumeration, and partial failures preserve input-stream ownership
and release allocated state. MacBinary padding and embedded-fork positions use
wide arithmetic, including bounded streams used for checksums and data forks.

This is a shared parser correction. There are no filename exclusions, AGS-specific
bypasses, or WAGE detection workarounds. Standalone raw forks of 4 GiB or larger
are rejected instead of truncating their size.

## Validation and limits

- Twelve focused synthetic tests cover the reported header, truncated structures,
  overflow, nested ranges, partial cleanup, ownership, checksums, valid maps and
  wide MacBinary data-fork bounds. The full 454-test unit suite, two additional CE
  regressions and five static portable-storage checks passed during development.
- All-engine detection of the complete unchanged Adventure: Welcome to the Genre
  distribution completed with exit code 0 and the exact `ags:advwelcome` match.
  Valid synthetic raw, MacBinary and AppleDouble fixtures also completed WAGE
  fallback detection normally.
- Final release validation and immutable executable/archive hashes accompany the
  published package and release notes. Development results above are identified
  separately from checks performed against the versioned release executable.
- Macintosh compatibility checks use synthetic fixtures; no real Macintosh game
  distribution was tested. No additional gameplay test was performed. The owner
  previously confirmed Adventure: Welcome to the Genre playable through AGS.
- No downloaded game program, installer, script or DLL was executed. Original
  game files, archives, final game ZIPs and approved CE installations were retained.

## Existing functionality and installation

The complete enabled engine set and previous CE functionality remain included,
including experimental Gooka with Czech/English text, desktop window layouts,
sessions and achievements, existing cheat options, MI4 Windows/PS2 support, AGS,
Nox, Space Quest V: Trash Talkin' Edition support and the opt-in native Test CLI.
The upstream foundation remains ScummVM 2026.4.0. Existing gameplay limitations,
including Gooka's experimental status, remain as described in the v0.1.5 notes.

Extract the entire ZIP into a short, writable directory and keep the executable,
DLLs and resource files together. Strict portable storage remains permanent:
configuration, saves, sessions, achievements, screenshots, logs, caches and
temporary application data stay beneath the executable directory. Official
ScummVM profiles and saves are not imported or shared automatically.

Preserve and back up the complete existing installation directory and its portable
data when upgrading. Do not overwrite a configured INI with the package's fresh
INI. No signing, installer or automatic migration is provided. Independent
bit-identical executable rebuilding remains unverified.
