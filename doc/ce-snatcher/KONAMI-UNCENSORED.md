# KONAMI live uncensored activation

Submitting the exact alphabetic code KONAMI at the JORDAN computer (scenario62, presentation resource12, including its keyboard view) enables the Uncensored game option. Typing without submitting does nothing. Other names and other text-entry owners are unaffected. If already active, the resource cache and configuration are left unchanged.

Activation validates the existing five-resource sidecar against original and patched digests in a temporary owner, parses and validates patched SP25, checks cross-scenario targets, and proves no retained narrative cursor changes semantics. Only then does the live resource owner commit the cache. Its preloaded SP25 scenario is replaced in the same coordinator visit; existing decoded computer graphics remain valid. The option is persisted in the active game profile. Subsequent scenes and the patched SP25 script therefore use uncensored data in the current engine instance, without reload or restart. The sidecar remains required. A missing/invalid sidecar reports an on-screen message and leaves the original computer response playable and the option unchanged.
